# Code-Robot-ALPHA 🤖

> A fake IDE that generates code forever. Just for fun.

That's it. That's the project.

---

## What is this?

It's a fullscreen fake IDE that looks suspiciously real — dark theme, syntax highlighting, a file tree, a blinking cursor, a terminal with compiler warnings, and an AI chat panel on the right — and it just… keeps generating code. Infinitely. For no reason at all.

Open it, stare at it, feel productive without doing anything.

---

## Usage

```bash
# 1. Clone it
git clone https://github.com/your-username/code-robot-alpha.git

# 2. Open index.html in your browser
# 3. Look busy
```

No npm. No build. No config. One file. Zero purpose.

---

## Features (for a thing with no purpose)

- 🖥️ Fullscreen fake VS Code vibes
- ⌨️ Code types itself out line by line, forever
- 🎨 Proper syntax highlighting (keywords, types, strings, functions)
- 📁 File tree that switches files occasionally
- 📟 Terminal with fake `tsc --watch` output and random warnings
- 🤖 AI chat panel with scripted conversations and typing indicators
- 🗺️ Minimap that fills up as code appears
- 🔄 Infinite loop — it never stops, never crashes, never ships
